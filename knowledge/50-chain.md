# Robinhood Chain and wallets

| Property | Value |
| --- | --- |
| Network name | Robinhood Chain |
| Chain ID | 4663 |
| Native gas asset | ETH |
| RPC | https://rpc.mainnet.chain.robinhood.com |
| Explorer | https://robinhoodchain.blockscout.com |

- Any EVM wallet that supports custom networks works (for example MetaMask, Rabby). Add the network with the values above if the wallet does not list it.
- Users need ETH **on Robinhood Chain** for gas. ETH on Ethereum mainnet or another L2 must be bridged first.
- A transaction hash can be checked at https://robinhoodchain.blockscout.com/tx/<hash>.
