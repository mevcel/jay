# Code of conduct

This project serves the Pons Family community, and the same standards apply here as in our channels.

- Be respectful and assume good intent.
- Keep discussion on the work: the code, the knowledge base, the behavior.
- No harassment, personal attacks, discrimination, or doxxing.
- No shilling tokens, posting referral links, or asking people to DM you "for support".
- Never ask anyone for seed phrases, private keys, or funds.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

Report problems to **contact@ponsfamily.com**.
